# Veilgard Notice

Veilgard is a rebranded self-hosted deployment based on the open-source Stoat
self-hosted stack.

- Upstream self-hosted project: https://github.com/stoatchat/self-hosted
- Upstream web client: https://github.com/stoatchat/for-web
- Upstream backend/services: https://github.com/stoatchat/stoatchat

The upstream self-hosted and web projects are licensed under AGPL-3.0. Keep the
included `LICENSE` file, publish the source for any deployed modified version,
and keep the `/source` route reachable for users of the hosted instance.

The Veilgard branding files added here are local deployment changes and do not
use Stoat brand assets.
